# Security policy

Please report vulnerabilities privately to **info@kristohanon.com**. Do not open a public issue containing API keys, mailbox credentials, personal prayer intentions, contact-form submissions, subscriber addresses, or instructions that could be used to abuse the service.

Kristohanon does not provide emergency, medical, or mental-health services. Immediate safety concerns should be directed to local emergency services and qualified professionals.

Supported security fixes are applied to the current `main` branch. Reports should include the affected page, the impact, and safe reproduction steps without accessing another visitor’s information.
